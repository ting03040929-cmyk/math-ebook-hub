# 國中特教數學 自製電子書教材庫 (Math Ebook Hub)

專為國中特教資源班、個別化教學與課堂大屏設計的**雙模式教學互動電子書學習網**。

🌐 **線上教材首頁 (GitHub Pages)**：  
https://ting03040929-cmyk.github.io/math-ebook-hub/

---

## 🎯 核心功能亮點

1. **🖥️ 教師端大屏／投影教學模式**：
   - 逐題點擊顯示紅字答案。
   - 懸浮工具列一鍵全開／全隱答案（👁️/🙈）。
   - 4 色螢光筆/板書筆（黃、紅、藍、綠）與 3 種粗細，支援一鍵清除（🧹）。
   - 章節目錄導覽選單（📑），平滑跳轉各關卡。
2. **🔊 原生語音報讀（TTS）與答案防洩漏**：
   - 支援 0.8x、0.9x、1.0x 語速微調。
   - 點擊 📢 即時朗讀題目與觀念，正在朗讀的區塊自動亮起柔和黃色光暈（`.speaking`）。
   - **嚴格答案保密**：題目中的解答（`.ans-reveal`）自動置換為「空格」，絕對不會唸出答案，讓學生安心聽題思考。
3. **🖨️ 學生端純淨 A4 列印**：
   - 按 `Ctrl + P` 或工具列 🖨️，自動隱藏所有工具列、畫布、連線與答案紅字。
   - 嚴格 1 頁對應 1 張 A4，杜絕溢頁產生多餘空白頁，還原為乾淨的白紙作業卷。

## 🚀 如何擴充新教材
只要將新產出的電子書 HTML 檔案放入本儲存庫，並在 `index.html` 首頁卡片中加入對應的連結與簡介，即可一鍵擴充！
